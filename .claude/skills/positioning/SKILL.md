# Product Positioning

## Intent

Give the product one sharp, defensible place in the customer's mind. This skill enforces the classic positioning-statement structure, built from the audience and competitive work already done — not re-derived. It composes with [[audience-segmentation]] (who), [[competitive-analysis]] (the gaps), [[market-analysis]] (the opportunity), and [[product-specs]] (the what & why).

## Rules

1. **Reuse, don't re-derive.** Pull the audiences from [[audience-segmentation]] and the gaps from [[competitive-analysis]]; don't redefine *who* or re-run the analysis.
2. **Follow the positioning shape.** *For [audience] who [need], [product] is a [category] that [key benefit] — unlike [main alternative], which [gap].* Fill every slot.
3. **Lead with differentiated impact, not a feature list.** The "unlike us" claim is an **outcome** the audience gets that rivals can't deliver — grounded in the whitespace, not a spec sheet.
4. **One primary audience, one core benefit.** Positioning is sharp, not a survey. If it tries to be everything to everyone, cut.
5. **Concede table-stakes as table-stakes.** Don't claim shared capabilities as differentiators; the edge is only what's genuinely **unclaimed**.
6. **Honest and defensible.** Every claim traces to the market/competitive evidence; no superlatives you can't back. Flag assumptions.
7. **Keep the statement tight.** One short statement (plus an optional one-sentence form); sticky-note inputs stay short.

## Checklist before calling it done

- [ ] Audiences + gaps reused from the prior analysis (not re-derived)
- [ ] Every slot filled (audience / need / category / benefit / alternative / gap)
- [ ] "Unlike us" is differentiated impact, not a feature list
- [ ] One primary audience + one core benefit; sharp, not a survey
- [ ] Table-stakes conceded; only unclaimed value claimed as the edge
- [ ] Every claim traces to evidence; assumptions flagged

## When unsure

If the differentiator is a feature several rivals also have, it's **table-stakes** — find the unclaimed one. If the statement names two audiences and three benefits, it isn't positioning yet — cut to one each. If a claim can't be traced to the competitive/feature analysis, don't make it. Hand the sizing to [[market-analysis]] and the competitor detail to [[competitive-analysis]].

## Examples

**Differentiator — ❌ feature list vs ✅ differentiated impact**
- ❌ "…unlike others, we have provenance labels, a registry, and workflows."
- ✅ "…unlike governance tools that don't do the work and AI tools that don't govern it, we make the work itself trustworthy for a non-expert."

**Scope — ❌ everything-to-everyone vs ✅ one audience + one benefit**
- ❌ "For nonprofits, enterprises, and schools who want AI, we do governance, work, and training."
- ✅ "For small nonprofits accountable for responsible AI, we're the governed AI workspace that does the work *and* proves it's safe."

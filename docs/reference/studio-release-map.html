Release 1a · 25 cards · all Done

Release 1a: the Co-Pilot-first MVP

A thin walking skeleton through every layer, then the hero feature: should we use AI for this?

Epic 0 · Foundation

8
  • Next.js + TypeScript app on Vercel; Supabase auth with org, profile and roles
  • Default-deny row-level security; append-only audit log
  • Data model and migrations; governed-run pipeline shell
  • CI gate (lint, types, tests, build, dependency + secret scan)
  • Standards library authored: NIST / EU AI Act / ISO 42001 as plain rules

Epic 4 · Governance Co-Pilot

6
  • The "should we use AI for this?" flow
  • Use / conditional / don't answers, each citing its standard
  • Safer alternatives; "no safe path"; out-of-scope points to a human

Epic 1 · Policy seed

5
  • Seed questions, step-by-step intake, plain-language rule format
  • Starter policy generated from the answers (risk first)
  • Policy inheritance into every governed run

Epics 2 + 5 · Registry and rule-check

3 + 3
  • Automatic logging of every governed task, with no sensitive content stored
  • Deterministic rule-check engine; block or flag with a plain reason
  • Provenance label on every output

Key decisions: ADR-0003 (layers), 0007 (sign-up trigger), 0008–0010 (standards, policy, Co-Pilot data and logic), 0011–0013 (Next.js, Vercel, Supabase), 0014 (rule-check is code, not an LLM).
